# 0.2.1 · 新版卡片应用与开局修复

新版成为 Web 和 Android 的唯一首页，19 位人物、收藏与抽取次数、开局设置、词条和资金规则、模型连接、钱包查询、战场资金曲线和战神榜接入当前服务。旧书签转到新版，已有账本和收藏保留迁移路径；移除随机离线演示和默认示例局。

本版修复 0.2.0 多对局预计算接口传递遗漏：开局前可以准备决策，实际下注仍须等待开盘行情并通过资金与数据时效检查。不会提前冻结资金或创建订单。中文、英文、日文、韩文及手机/平板/桌面布局继续保留。

## 下载与升级

- Android：`10u-warrior-0.2.1-android-preview.apk`，Android 7.0+，versionCode 17。Release 构建、沿用测试证书，供侧载试用；不是商店签名包。同签名覆盖安装保留数据，不要先卸载。
- 电脑：`10u-warrior-0.2.1-web.zip`。安装 Node.js 22+，解压后 Windows 双击 `start-web.cmd`；macOS/Linux 执行 `npm ci --omit=dev`、`node start-web.cjs`。升级保留 `.data/`，每份数据只运行一个服务。
- 新用户先抽卡再开局，本地规则无需模型 Key 或钱包。旧 `?offline=1` 不再启用演示数据。
- `SHA256SUMS.txt` 提供附件校验值。此版替代 `v0.2.0-preview.1`，旧附件不覆盖。

## 验证与范围

当前维护测试显式限定在 `test/`，63 个文件、402 项测试通过；修正旧自动发现将解压发布包测试与夹具计入总数的问题。122 个当前服务、构建和分发脚本检查通过。[Linux CI](https://github.com/fan944721805-pixel/10u-warrior/actions/runs/34892355847) 通过。完整 UI 套件覆盖收藏、API、钱包、设备、开局、资金、战场、设置、排行、行情及四语言 156 个布局，原生运行时协议验证通过。Android Release 构建、签名和 64 个客户端文件核对通过，四个发布附件已实际下载并核对 SHA-256。完整结果见[迁移记录](https://github.com/fan944721805-pixel/10u-warrior/blob/main/docs/strategy-system/12-production-migration.md)。

所有对局使用模拟资金；钱包用于可选授权与资产查询，当前界面不提供真实下单。验证使用隔离服务和协议夹具，没有本版本真机升级、真实模型调用或新的真实钱包授权证明。系统省电策略可能限制后台，进程恢复后对局保持暂停。
