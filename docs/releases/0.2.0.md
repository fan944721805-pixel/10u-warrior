# 0.2.0 · 新版卡片应用

> 已被 0.2.1 替代。此版发布后 CI 暴露多对局预计算接口遗漏，升级请使用 [0.2.1](https://github.com/fan944721805-pixel/10u-warrior/releases/tag/v0.2.1-preview.1)。旧附件保留追溯。

新版成为 Web 和 Android 的唯一首页：先抽取人物卡，再开局观察策略表现。旧书签自动跳转，已有正式对局和收藏保留迁移路径。

- 19 位人物，包含 KZG 与孙哥反指。收藏次数、属性刷新、重复卡替换接入服务保存，失败重试不重复扣次。
- CT-1 词条、SC-2 资金规则、全局情绪和模型绑定进入对局快照；10/100 U 快捷本金与自定义金额并存。
- 战场展示模拟下注、决策依据和资金曲线。战神榜按最近一局、最近三局、全部汇总结算表现。
- 右上角 API 和钱包入口接入既有服务；Android 支持原生授权恢复、后台服务、通知和桌面小组件。
- 中文、英文、日文、韩文与手机/平板/桌面布局；移除过期示例文字、随机离线入口及默认 A/B/C 示例局。

## 下载与升级

- Android：`10u-warrior-0.2.0-android-preview.apk`，Android 7.0+，versionCode 16。Release 构建、沿用测试证书，供侧载试用；不是商店签名包。使用相同签名覆盖安装，保留应用数据，不要先卸载。
- 电脑：`10u-warrior-0.2.0-web.zip`。安装 Node.js 22+，解压后 Windows 双击 `start-web.cmd`；macOS/Linux 执行 `npm ci --omit=dev`、`node start-web.cjs`。升级时保留 `.data/`，每份数据只运行一个服务。
- 新用户先抽卡，再点“开一局”；本地规则无需模型 Key 或钱包。旧 `?offline=1` 不再启用随机演示。
- `SHA256SUMS.txt` 提供附件校验值。Web 包来自此版本的已提交源码；源码和文档见仓库。

## 验证与范围

发布前 JavaScript 检查和新版 UI 服务回归通过；涵盖四语言 156 个页面/弹窗布局、钱包 60 个组合、设备 12 个组合、资金/开局/排行和行情订阅。原本地 Node 报告的 722 项包含重复发现的旧测试与夹具；后续 Linux CI 两项失败，0.2.1 修复并改为显式运行当前维护测试。Android Release 编译、签名验证、64 个客户端资源与 APK 逐文件比对通过，旧 UI 资源与调试 Activity 未进入 APK。

这些验证使用隔离服务、模拟账本和协议夹具。本次没有新的真机升级验证、真实模型调用或钱包授权；没有提交真实订单。所有对局使用模拟资金，钱包连接用于可选授权与资产查询，当前界面不提供真实下单。系统省电策略仍可能限制后台，进程恢复后对局保持暂停。

项目不是 Binance 官方产品。外部模型可能产生供应商费用。详细实现与验收见 `docs/strategy-system/12-production-migration.md` 和 `13-release-audit.md`。
