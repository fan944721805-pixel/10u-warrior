# 全局设置与个人情绪

版本：SC-2.0 迁移中 · 2026-09-15。五项设置已接入新版卡片对局；CT-1 词条状态增量已接入，供应商温度适配已接入。旧版无卡片快照的账本保留原有策略计算。返回 [策略文档目录](README.md)。

## 8. 全局控制与情绪计算

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 全员手痒 Bᵤ | 0–100 | 0 |
| 全场上头 Bₜ | 0–100 | 0 |
| 情绪放大 G | 0–200%，计算时 /100 | 100% |
| 冷静速度 D | 慢/标准/快，每轮回落 3/6/12 | 标准 |
| 全场变化 Bᵥ | 0–100 | 0 |

每轮先按唯一结算事件更新个人状态，再计算有效参数。敏感度 S 来自卡片，个人上头初始 0；盈利事件增量 8×S/100×G，亏损事件 12×S/100×G，平局 0，合并后减去 D，截断至 0–100。已处理 eventId 不再计入。

有效手痒：Uₚ=clamp(卡片U+状态增量,0,100)，U=Uₚ+(100−Uₚ)×Bᵤ/100。

有效上头：T=Tₚ+(100−Tₚ)×Bₜ/100。有效变化：V=Vₚ+(100−Vₚ)×Bᵥ/100。最终数值展示取整，计算保留精度。情绪放大只作用于个人结算增量，不再重复乘全场值。

U 只在人物方法许可范围内影响确认严格度。T 按人物胜负反应影响建议仓位与等待；谨慎人物输了可以更谨慎，不让所有人变成追损者。V 影响合法备选之间的抉择和模型生成温度，不提高证据得分或概率。

预设：保持本色=0/0/100%/标准/0；热闹一点=40/30/100%/标准/20；全员上头=100/80/150%/慢/50。预设不改变资金限制。

按最新交互要求，按钮为“应用”。滑杆与预设只修改弹窗草稿；应用时一次提交五项设置及打开弹窗时的 `controlsRevision`。服务原子保存并增加版本，影响即将提交的下注，不限于下一轮。已提交订单、冻结金额和本轮已生成的占卜不改写。旧预计算和尚未提交订单的在途决策失效；实时进场仍遵守现有冷却与信号门槛。

重复提交相同值不重复增加版本；不同值携带旧版本则拒绝并返回 `CONTROLS_CHANGED`。界面读取最新版本供重新打开后调整，失败不显示保存成功。结束或结算中的对局不能修改设置。Web 与 Android 原生运行时复用同一规则。

个人情绪与轮次冷却边界保存在账本中。仅 `OPEN` 订单首次结算时增加情绪，已开始并结束的对局轮次各冷却一次；暂停期间没有开始的新轮次、刷新、重试和离线时间不额外冷却。结算延迟时不推断胜负，收到结算后再增加情绪，不追补假想事件。迁移旧卡片账本从零个人情绪开始，不追算历史结算。

本地卡片决策中的变化参数仅可使临界选择观望，不再增加置信度或翻转技术方向。外部模型收到完整有效值与硬规则；模型温度按下述能力适配，CT-1 词条状态机已接入，规则与验证见 [词条执行与恢复](02-card-generation.md#ct-1-实施边界与恢复规则)。


## 模型温度适配

`ai-sampling.cjs` 是服务端和 Android 共用适配器。使用已经计算的有效 V，映射为 `0.15 + V / 200`（0.15–0.65）；不会再重复叠加全场变化，不修改证据得分。该范围是本项目的产品选择，不是供应商建议的最佳交易参数。

- OpenAI：已识别的 GPT-4o/4.1 标准、mini/nano 及日期快照发送温度。GPT-5.1/5.2/5.4 标准及日期快照显式使用 `reasoning_effort: none` 并发送温度；这些模型的默认推理级别就是 none。不会将其他型号或 Pro 自动替换为它们。[OpenAI 参数兼容规则](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.4)、[GPT-5.1/5.2 规则](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.2)。
- Claude：Sonnet/Opus 4.5、4.6 与 Haiku 4.5 及其日期快照发送温度。后续不支持采样参数的型号省略温度，不借固定 1.0 假装变化值生效。[Claude Messages 参数](https://platform.claude.com/docs/en/api/messages/create)。
- DeepSeek：已识别的 chat、V4 flash/pro 非思考请求发送温度。连接管理和环境变量入口统一构建请求；reasoner 不发送温度。思考模式下温度没有效果，不能宣称它随 V 改变。[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
- 自定义连接和未核实的型号保留服务商默认采样，不通过名称前缀假设能力。V 仍在结构化决策上下文中；接入新型号时需核实能力并扩充有测试的名单。

连接检查不携带卡片温度。正式请求记录 `sampling`：有效 V、实际温度或 null、应用/省略原因、适配版本；账本的模型请求与决策元数据保留该记录。省略原因不是供应商返回的实测结论，未知能力明确记为未知。请求审计不含 API 密钥。温度不能保证重放同样的外部模型输出。

验证：`test/ai-sampling.test.cjs` 覆盖多供应商请求、有效全局值、边界/未知模型、环境变量入口及元数据；`test/mobile-runtime.test.js` 验证打包运行时应用全局设置后发送的真实请求结构与重载记录。上游为隔离夹具，没有调用用户模型或真实交易。
