# 资金规则与版本差异

版本：SC-2 资金规则 · 2026-09-15。新版卡片对局已接入；CT-1 词条状态机已接入。返回 [策略文档目录](README.md)。

## 版本边界

新卡片使用 `capitalVersion: SC-2`，资金限制进入冻结策略哈希（schema 2）。已有 schema 1 卡片恢复为 SC-1，保留原哈希和原资金行为，不通过读取或重构修改旧账本。新建卡片对局拒绝 SC-1；带卡片的 SC-2 对局必须有完整决策引擎，不能落入旧 A/B/C 随机下注路径。

旧版普通最低下注仍为 5U，历史翻本模式保留。SC-2 的模拟最低下注为 **0.10U**，金额按分向下取整。没有自动全仓翻本例外，不为凑最低额增加下注；没有合法档位时观望。

## 开局冻结的限制

| 参数 | 范围与默认 | 口径 |
| --- | --- | --- |
| 单次上限 | 1–100%，默认 100% | 每位的可用资金乘用户上限，再与人物上限取小 |
| 未结算总额上限 | 1–100%，默认 100% | 每位可用资金加冻结本金的比例；扣除该人物全部未结算本金后，才是新增下注余量 |
| 亏损停止线 | 可不设；设置时 1–99% | 可用资金+冻结本金−累计追加本金，低于或等于初始本金×(1−亏损百分比)时触发 |
| 全仓权限 | 默认关闭 | 用户开启且人物允许，并通过强信号、置信度、优势、上限与剩余暴露检查后才可用 |

每位人物独立计算。开局弹窗的“资金限制”折叠区可调整这些参数；正式创建后冻结，人物详情中可查看。对局中的全局气氛设置不能更改资金限制。

模型可选比当前建议更小的合法档位，也可观望。凉兮仍只有 50% / 100% 两档，普通单次上限不足 50% 时不能改成其他比例下注。其余人物沿用自身正常阶梯，情绪影响目标档位后向下选择仍合法的档位。任何合法档位不足最低额或超过待结算暴露余量时都不下注。

## 停止与结算

停止线触发后持久化 `capitalStopped`，刷新、恢复或追加资金不会自动解除。已有订单继续结算，不把预期盈利计入净值；最终净值不保证刚好停在阈值。全部人物停止且没有未结算订单后，对局以 `CARD_STOP_LOSS` 原因结束。

读取快照不修改停止状态；结算和正式运行推进负责记录触发事件。每个实例保存初始本金、追加本金、可用余额、冻结金额和结算记录。
