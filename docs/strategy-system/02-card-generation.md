## 4. 风格、词条与数值如何生成

### 4.1 生成顺序与概率

1. 每次从全部可用人物中等概率随机选择原型；不提供人物池选择或指定人物抽取。
2. 从该人物兼容的非原版风格中等概率选择一个主风格。原型图鉴仅提供介绍，不直接授予收藏。
3. 从该风格允许的指标方案选一个；保留所有人物必需输入。
4. 应用风格偏移，再对 U/S/V 分别取整数 -3…3 的均匀微调，截断到人物范围。
5. 加入风格固定行为词条，最多一个有持续/冷却的特殊状态。首版不另外无限随机叠词条。
6. 校验方向来源、资产、指标、档位、触发效果兼容性，得到完整卡；校验失败不收藏、不扣费、不无限重试，返回配置错误。
7. 根据实际风格和效果命名，不允许名为疯狂但实际生成低手痒、低参与度的卡。遇边界截断而风格差异不足，预先从兼容池剔除该风格。

随机种子使用本机随机源产生并保存，生成算法版本与每步选择记录一起冻结。固定种子只保证同规则版本的卡片生成一致，不保证外部模型或实时行情再次调用一致。

| patient / 耐心等位 | 由主风格 U 下降表达 | 卡片基础属性 |

| rethink / 失效重判 | 候选被角色判定否决后清除，不能因执着保留 | 本轮即时 |
| snowball / 连胜膨胀 | 连胜 2 笔后，合法仓位意愿 +15 点 | 2 个完成的决策轮；失利结束 |

| retreat / 输了缩手 | 连败 2 笔后普通建议仓位 ×0.7 | 首笔盈利解除；最多 3 轮 |
| waitFatigue / 坐不住了 | 连续观望每轮有效手痒 +5，最多 +15 | 首笔有效下注后清零 |
| protect / 利润护体 | 净值达本金 1.5 倍后普通建议仓位 ×0.7 | 低于 1.3 倍解除 |
| insight / 我悟了 | 连胜 3 笔后有效手痒 +10、合法仓位意愿 +15 | 2 轮，结束后冷却 5 轮 |
| cooldown / 贤者时间 | 单笔已结算盈利 ≥ 初始本金 10% | 停止新下注 2 轮，冷却 5 轮 |
| resonance / 信号共振 | KZG 的趋势、结构和流量三组强确认同时成立 | 本轮优先高一档，冷却 3 轮 |

凉兮的仓位意愿在 50/100 两档中选择，不能乘出 35%、70% 等新档位；普通人物仍受各自仓位档位和上限约束。无法映射的词条不能生成给该人物。保护利润与原人物同类效果取更严格的一项，不重复计算。

每张卡最多两个基础风格解释词条、一个反应词条、一个特殊状态。暂停效果优先于增加出手意愿。同事件只触发一次；特殊状态生效期间不续杯。重试、刷新和断线不消耗轮数，完成决策轮次才推进持续/冷却。


## 11. 抽取、收藏与自定义

抽卡区仅保留抽卡和查看卡册入口。初始获得 5 次抽卡机会；次数不足 5 时，每 10 分钟恢复 1 次，最多储存 5 次。首次消耗后开始恢复计时，后续消耗不重置已有计时。次数为 0 时禁止抽取，并显示下一次恢复倒计时；满额期间不额外积攒时间。

每次成功抽取消耗 1 次，新人物自动收入卡册；重复人物暂存新结果，确认覆盖前不加入卡册；刷新不重置次数或重复扣除，离开页面后按经过的完整时间段恢复。无次数、重复点击和生成/存储失败不产生额外消耗。多个客户端共享应用服务的次数、集合版本和幂等回执；次数与卡片在同一个原子文件提交。页面倒计时不增加额度，服务时钟决定恢复。此部署不提供多主写入或跨设备账户同步。

每个人物仅保留一张卡；重复人物的新结果可放弃，或确认覆盖唯一的已有卡，覆盖不额外扣除次数。详见 [属性刷新与重复卡覆盖](11-card-upgrades.md)。稀有度仅由组合稀有程度与外观表达，不给予信号优势；首版不强制 SSR 分级。

卡册默认包含已拥有的卡片，以及每位尚未拥有的人物的一张图鉴占位。增加“已拥有 / 未拥有”筛选和人物解锁进度；未拥有使用灰色头像及文字标识，只可查看原版介绍或去抽卡。原版图鉴不提供直接收藏和加入阵容，不能绕过抽卡次数获得人物。抽到后自动点亮该人物并替换未拥有占位；相同人物只保留一张实际卡片。

当前提供消耗 1 次机会的属性刷新，只随机更新 U/S/V，人物与词条、指标保持不变。未来手动修改抽到的参数采用“复制为自定义变体”，保留原卡，只允许人物范围内编辑指标方案与 U/S/V，显示差异和自定义标识；名字可自定，但不能使用户误以为改变了核心规则。自定义版本仍是整张卡。

用户昵称不翻译。卡片系统名随语言切换。删除收藏卡不删除历史对局副本；阵容中引用的卡在删除前提示，或保留不可见快照。COL-1 提供收藏、属性刷新与确认覆盖；服务成功保存后才更新页面。阵容与显示偏好沿用浏览器偏好，具体恢复规则见属性刷新文档。



## CT-1 实施边界与恢复规则

`public/card-lab-data.js` 的 `traitsFor` 生成词条；`card-policy.cjs` 冻结词条版本；`card-traits.cjs` 处理持久化触发、持续和冷却。新建卡片使用 CT-1、SC-2 和 schema 3 哈希。历史 schema 1/2 仍按 CT-0 原词条恢复，不重算历史身份，也不追补过去的触发；不能用 CT-0 创建新卡片对局。

| 主风格 | CT-1 固定词条 |
| --- | --- |
| 疯狂 | 手痒难耐、连胜膨胀、我悟了 |
| 隐忍 | 耐心等位、失效重判、坐不住了 |
| 狙击 | 技术确认、耐心等位 |
| 追击 | 技术确认、手痒难耐、坐不住了 |
| 谨慎 | 耐心等位、输了缩手、贤者时间 |
| 执着 | 失效重判、急于翻本 |
| 精算 | 技术确认、利润护体 |
| 趋势 | 技术确认、耐心等位 |
| 反指 | 反指、耐心等位、失效重判 |
| 原版 | 原型核心 |

KZG 的狙击/趋势额外带信号共振。风格仍受人物兼容池限制，不能根据这个表任意组合。反指属于人物方向身份，不占两个基础风格词条名额。

- 手痒加成先加到卡片基础值（封顶 100），再计算全员手痒，避免重复叠加。词条不增加指标置信度、不改变人物方向来源。
- 技术确认禁止外部模型在确认不足时利用高 U 发起弱信号试探。决策提交前仍重新检查当前指标、账户和控制版本，失效候选不能因失效重判或执着而保留。
- 所有仓位效果均向下映射到该人物合法档位；缩注后的目标低于最小合法档则观望，不抬高最低下注。凉兮的 50/100 档与全仓条件保持不变。同类缩注取更严格的一项。
- 贤者时间期间跳过新模型调用与新下注；已有订单继续结算。暂停决策轮只推进持续/冷却，不算连续观望。
- 结算按订单 ID 去重。持续和冷却只消耗真实完成的决策轮；模型错误、预计算、刷新、重复轮次和单纯经过时间都不推进。实时规则只得到观望、没有模型任务时仍保存记录。
- 每个决策轮记录当时效果的序号。延迟结算刚触发的效果，不会被早于触发的决策轮扣减。账本重载恢复同一状态；CT-1 缺失或损坏的状态拒绝恢复，不能静默重置。
- 战场详情读取实际触发、剩余轮数、冷却和手痒加成，四种语言共用状态字段；读取详情不修改状态。

验证：`test/card-traits.test.cjs` 9 项覆盖组合、旧版本恢复、真实引擎结算、去重/延迟/持久化、仓位与确认边界；打包原生合同测试核对 CT-1 状态与服务端哈希一致；战场正式 HTTP 验证涵盖四语言双尺寸。行情和模型使用隔离夹具，未调用用户钱包或真实交易。

COL-1 的服务持久化、页面切换、旧集合备份迁移及四语言验证已完成；详见 [属性刷新与重复卡覆盖](11-card-upgrades.md)。自定义变体编辑与跨设备同步不属于当前已实现能力。
