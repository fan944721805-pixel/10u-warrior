# 产品定义与数据边界

版本：SC-2.0-design · 2026-09-14。本文保留该日期的目标设计；当前实施进度及后续 UI 调整以 [正式迁移记录](12-production-migration.md) 为准。返回 [策略文档目录](README.md)。

## 1. 产品定义与首版范围

**一个策略就是一张完整人物卡。** “疯狂版凉兮”的人物、词条、指标、数值和触发行为都属于这同一张卡；这些要素不是独立可抽取或装备的卡牌。

生成关系：人物原型 → 兼容风格与行为词条 → 兼容指标方案 → 有界数值变化 → 人物约束校验 → 完整卡。

首版目标包括：18 位人物、原版和人物变体、全人物随机抽取、卡册、原版对比、最多 8 张卡的阵容、每实例 AI 模型绑定与实质决策、实例依赖、五项全局设置、逐轮解释、旧版兼容、中英文和多端 UI。不做付费抽卡、碎片、升星、多人联机或新的真实交易通道。

这次提供完整文档与可体验 UI，策略执行接入按第 18 节分期完成。不得用原型中的样本收益证明策略有效。


## 2. 一张卡与一场对局分别保存什么

| 对象 | 保存内容 | 生命周期 |
| --- | --- | --- |
| 人物原型 | 不可变方向来源、资产限制、仓位档位、人物允许池 | 随规则版本发布 |
| 策略卡 | 原型、风格、词条、指标方案、基础属性、规则版本、抽取种子、来源 | 抽取后固定 |
| 收藏副本 | 收藏时间、昵称、标记 | 用户管理，不改策略能力 |
| 阵容实例 | 卡片副本、实例 ID、模型配置、依赖目标、独立资金 | 一场对局独有 |
| 运行状态 | 连胜连败、个人上头、等待轮数、触发状态、冷却 | 按轮次和已结算事件变化 |
| 全局控制 | 全员手痒、全场上头、情绪放大、冷静速度、全场变化 | 当前对局；下一轮生效 |
| 决策记录 | 本轮冻结输入、来源、证据、调整、许可、模型输出、执行结果 | 追加保存，不回写历史 |

卡册显示基础值，战场显示有效值并能展开来源。例如卡片手痒 80，全员手痒 50 后有效值 90；卡册仍为 80。

同一人物的两张变体是不同卡片，同一卡片在不同对局也是不同实例。引用和记账均使用实例 ID，不能用“凉兮”或翻译后的名称作唯一标识。
