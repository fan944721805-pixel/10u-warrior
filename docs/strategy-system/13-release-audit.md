## 发布门槛

1. `npm run check` 检查当前服务、构建脚本及分发脚本。
2. `npm test` 重建 Android 共用运行包并验证业务合同。
3. `npm run verify:ui` 验证当前服务交互、错误/恢复和四语言布局。
4. `npm run mobile:verify` 验证原生运行时与当前钱包、设备 UI；桥和上游响应是隔离夹具。
5. Android 0.2.1 / versionCode 17 Release 构建、签名检查和 APK 资源核对；沿用本地测试签名供 GitHub 侧载。
6. 提交文件检查、远端提交一致性、Web ZIP 与 APK 哈希、GitHub Release 下载核验。最终结果补记在迁移记录。

没有执行本版本真机升级、真实模型调用或新的真实钱包授权。没有提交实盘订单；自动化证明的是程序合同、模拟链路、UI 和可构建产物。自定义变体编辑、付费抽卡、跨设备同步和多人联机不属于当前产品功能；早期设计中相关提议不作为已实现能力宣传。
