# 10U 战神：抽卡策略系统与 UI 改版方案

版本：设计草案 v1。日期：2026-09-14。状态：已废弃，尚未实现。

> 本文错误地将词条设计成五张独立卡牌，不符合用户要求，不得作为实施依据。当前方案见 [单卡人物变体策略系统方案](2026-09-14_设计-单卡人物变体策略系统-report.md)：一个策略是一张完整人物卡，词条、指标偏好与数值共同形成该人物的变体，不能改变核心人设。本文其余内容仅保留为历史讨论记录，其中资金规则变更也不视为已获确认。

目标：通过抽卡和配卡，组装有鲜明性格、能解释每轮行为、最终仍受行情指标和资金规则约束的模拟策略。保留现有 17 个角色及其招牌规则，沿用已有指标、决策、模拟对局与账本实现。

本文件中的新增卡牌、数值、页面和迁移方式均为提案。现有代码事实单独列在第 1 节；拟议数值用于定义首版行为，不代表经过收益验证。

## 2. 一套策略由什么组成

固定五个卡位：角色卡 ×1、流派卡 ×1、性格卡 ×2、绝招卡 ×1。

| 组成 | 决定内容 | 用户能做什么 |
| --- | --- | --- |
| 角色卡 | 名字、头像、基础属性、不可变的核心规则 | 抽取或从收藏选择；查看兼容卡片 |
| 流派卡 | 指标组合、方向判断、有效信号与观望条件 | 普通角色换打法；特殊角色选择兼容的确认方式 |
| 性格卡 | 对胜负、等待、机会的反应 | 选择两张不互斥的性格 |
| 绝招卡 | 触发条件、暂时效果、持续时间和冷却 | 选择一张；对局中自动触发 |
| 指标面板 | 实际需要和参考的信息 | 默认自动搭配，高级模式增加参考项 |
| 资金设置 | 单轮上限、总暴露、亏损停止、盈利停止、是否允许全仓 | 独立设置，不依赖抽卡运气 |
| 执行配置 | 模型连接、版本、运行方式 | 沿用已有模型配置入口 |
| 策略身份 | 自定义名称、卡组版本、自动外号 | 保存、复制、另存为；自定义名称不翻译 |

稀有度只代表表现形式和机制稀有程度，不提高指标评分，不提供胜率或仓位特权。第一版不做付费抽卡、升星或数值养成。

## 4. 特殊人物的完整执行规则

### 4.1 装逼的人与 CZ

- 参考同一对局、同一币种、同一轮中已通过执行校验的 CZ 下注，不能参考一句模型意向或上一轮方向。
- 一个 CZ 时自动绑定；多个 CZ 时开局前选择一个具体角色实例，防止引用歧义。
- CZ 未入场、观望、失败、超时或本轮未形成有效下注，装逼的人观望，并显示具体原因。
- 卡片和全员手痒不能解除依赖，不能改成跟随 CZ。
- 提供“一键把 CZ 加入阵容”；阵容已满时给出替换入口，不静默挤掉其他人。
- 配装后因币种、仓位条件不兼容而无法发挥，开局预览明确提示；阵容未配齐依赖时不允许以有效卡组状态启动。

### 4.2 逆行者

- 默认沿用现有其他角色的有效下注、近 20 笔已结算记录、方向偏好和追损习惯形成权重。
- 默认不参考自己或其他逆行者，防止循环依赖。
- 可看到这一轮参考了谁、为什么权重大、反向结果如何产生。
- 没有符合条件的目标、目标方向打平或依赖数据不完整时，按既有规则观望或使用明确的历史不足分支；禁止编造战绩。
- 多人持续亏损且方向一致带来的加码仍受资金上限约束，不重复叠加同一来源奖励。

### 4.3 占卜师与风水师

- “开局抽策略卡”与“每轮占卜”是两个独立机制，UI 分别叫配卡、占卜，随机种子分开保存。
- 每轮卦象或三张牌只生成一次，记录种子、原始结果、候选方向。重试、刷新、模型重新解释不重抽。
- 首版沿用现有根据本轮行情等输入生成结果的方式，不额外改变占卜算法。
- 有明确占卜方向时，指标可允许或否决，不能偷偷改成相反方向下注。
- 中立结果保留现有高有效手痒、足够行情支持时的小注试探分支；战报注明“中立牌面，行情试探”，原牌面不变。
- 抽到看涨，但价差、波动或反向证据不满足该角色规则，结果是观望。不能把娱乐占卜分数当市场概率。

### 4.4 决策顺序

本轮先冻结配置和行情，再执行：普通技术角色、CZ、一姐、占卜角色等先决策；装逼的人等待绑定 CZ 的有效下注；逆行者最后读取允许参考的已完成结果。

只读取当前轮已完成的依赖。某一步超时，只影响依赖它的角色；不拖住无关角色，不在截止后补押。首版不开放任意互相跟随，避免循环引用。

## 5. 指标如何参与策略

每张流派卡声明“方向来源、必需输入、辅助输入、允许出手条件、必须观望条件”。沿用当前 26 项信息目录，不把每个指标再设计成一个卡位。

| 流派 | 核心信息 | 判断方式 |
| --- | --- | --- |
| 短线动量 | 短线涨跌、动量、ROC、主动买卖、盘口、长周期背景 | 找有支持的短线冲劲 |
| 趋势跟随 | EMA、MACD、ADX/DMI、短长周期涨跌 | 看趋势强弱与方向一致性 |
| 抄底摸顶 | 布林带、RSI、随机指标、ADX、长周期背景 | 找反转信号，区分震荡与强单边 |
| 突破追击 | 唐奇安、成交量、ATR、短线涨跌、买卖流 | 看突破是否得到成交和动量支持 |
| 资金侦察 | 主动买卖、订单簿、价差、涨跌背景 | 看流量方向及流动性条件 |
| 稳健观察 | ATR、波动率、价差、均线、长短线 | 风险合适且方向满足要求才下注 |
| 多信号共识 | 当前六项方向信号及长周期背景 | 分组看一致性，不用指标数量制造虚假把握 |
| 综合判断 | 当前超级AI所用指标 | 先识别趋势、震荡、危险局，再选规则 |
| 裸 K | 已收盘 OHLC、形态、市场赔率 | 按裸 K 形态判断，不暗中加入均线投票 |
| CZ / 一姐专属 | 当前趋势、量能、盘口及风险输入 | 只检查允许资产的上涨机会 |
| 反押专属 | 目标下注与历史、角色所需行情指标 | 目标给方向；行情负责风险和可执行性检查 |
| 占卜专属 | 卦象或牌面，涨跌、RSI、EMA、盘口、ATR、价差、背景、赔率 | 占卜提出方向，指标按现有规则确认或否决 |

具体指标计算继续使用已收盘数据与当前各流派时间映射。裸 K 保留既有对局周期对应 K 线周期的行为；新面板明确显示“本轮周期”和“指标采样周期”，不把两者混称。

用户可以增加可选参考指标，但不能取消必需输入，也不能仅靠勾选自动让某指标参与投票。没有进入决策规则的辅助数据应标为“只供参考”。所有必需行情及实际参与规则的数据须有效且未过期；辅助数据缺失则剔除并注明，不能填 0 冒充有效值。

技术流派需要满足自身方向规则。反押流派不强制与大多数技术指标同向，否则就失去了反押玩法；它仍须通过专属行情风险检查。所有策略仍允许观望。

界面显示“信号强度”和“模型自报把握”时分别命名；未经校准不得展示为真实胜率。赔率优势的校验沿用现有路径，性格、稀有度和上头效果不能人为抬高证据评分或估计概率来绕过它。

## 6. 性格卡、绝招卡与数值定义

### 6.1 属性分工

| 属性 | 作用 | 不能做什么 |
| --- | --- | --- |
| 手痒 0–100 | 更愿意接受策略允许的较弱机会、小注试探 | 无信号强押、解除人物依赖 |
| 情绪敏感度 0–100 | 控制胜负对当前上头状态的影响幅度 | 等同当前上头值 |
| 当前上头 0–100 | 在允许范围内提高出手意愿、改变仓位 | 突破单轮/总资金限制 |
| 变化度 0–100 | 同样合格的选项之间更有变化 | 凭空加信心、逆转固定方向 |
| 固执程度 | 面对反向证据维持候选判断的倾向 | 硬顶流派已明确否决的方向 |
| 仓位倾向 | 允许下注后，偏向哪个资金档位 | 跳过独立资金检查 |

配卡决定基础属性，首版高级面板保留手痒、情绪敏感度、变化度的手动覆盖：须显式启用“手动微调”，显示覆盖项并支持恢复卡组值。性格的触发行为仍来自卡牌，不能用一个滑杆替换整套机制。

### 6.2 首版 12 张性格卡

以下都是拟议初值。倍率针对“正常计算出的下注建议”，最终统一受硬限制；同一事件不能因重试重复触发。

| 卡片 | 触发与效果 | 退出或限制 |
| --- | --- | --- |
| 手痒难耐 | 基础手痒 +20 | 最高 100，不强制下注 |
| 选点挑剔 | 基础手痒 -20 | 最低 0，不增加信号分数 |
| 赢了就飘 | 连胜 2 笔后，接下来 2 轮建议仓位 ×1.2 | 不累乘；失利解除 |
| 见好就收 | 净值达到本金 1.2 倍，建议仓位 ×0.8 | 跌回触发线下解除 |
| 越输越犟 | 连败 2 笔后，接下来 2 轮手痒 +15 | 不保留被指标否决的旧方向 |
| 输了缩手 | 连败 2 笔后，建议仓位 ×0.7 | 下一笔盈利解除 |
| 坐不住了 | 每连续观望一轮手痒 +5，最多 +20 | 形成有效下注后清零 |
| 错过恐惧 | 记录的候选方向被行情证实但未下注，下一轮手痒 +10 | 只持续一轮；候选为空不触发 |
| 快速认错 | 新反向证据满足流派确认条件时，清除旧候选偏好 | 不凭情绪自动反手 |
| 冷静开局 | 第一轮只观察 | 第二轮解除 |
| 利润护体 | 净值达到本金 1.5 倍后，建议仓位 ×0.7 | 回落至 1.3 倍以下解除，避免频繁抖动 |
| 胆量慢热 | 第一笔下注前建议仓位 ×0.7 | 首笔完成结算后解除 |

首版同卡不可装两次。互斥组：手痒难耐/选点挑剔，赢了就飘/见好就收，越输越犟/输了缩手，越输越犟/快速认错，见好就收/利润护体。其他相反倾向可以共存，但预览必须解释先后关系。

仓位卡对凉兮只表达“更倾向半仓/全仓”，不产生 35%、70% 等非法档位；无法可靠映射的卡不进入凉兮候选池。角色固有盈利保护与同类卡不重复叠加，采用更强的一项。

### 6.3 首版 6 张绝招卡

| 绝招 | 触发条件 | 效果 | 持续 / 冷却 |
| --- | --- | --- | --- |
| 我悟了 | 连胜 3 笔 | 手痒 +15，建议仓位 ×1.25 | 2 轮 / 5 轮 |
| 贤者时间 | 单笔已结算盈利达到本金 10% | 暂停新下注 | 2 轮 / 5 轮 |
| 让我回本就走 | 净值低于本金 80% | 手痒 +15，建议仓位 ×1.2；回本后休息 | 最多 3 轮 / 8 轮；回本休息 2 轮 |
| 今天不对劲 | 连败 3 笔 | 暂停新下注，然后恢复常态 | 2 轮 / 5 轮 |
| 机会只留给有准备的人 | 连续观望 3 轮后出现该流派强信号 | 下一笔合格下注优先高一档仓位 | 1 次 / 5 轮；等待超过 2 轮失效 |
| 你是不是针对我 | 同一目标在近 3 个已结算共同下注轮次中，2 次与自己反向且目标盈利、自己亏损 | 后续 2 轮强化该目标的关注；仅既有反押角色可装 | 2 轮 / 5 轮；不改装逼的人绑定对象 |

“让我回本就走”不再自动全仓。全仓须同时满足角色允许、用户开启、策略条件和资金上限。暂停类效果优先于出手类效果。

状态统一使用：待触发 → 生效 → 冷却 → 待触发。触发依据为本轮冻结前已知的结算或行情事实。持续轮数只在完成一个决策轮次时推进；服务中断不空耗轮数。冷却从效果结束后开始，期间不能续杯或重触发。

## 7. 全局设置：每场对局独立生效

这里的“全局”指当前对局里的全部角色，不是同时改变所有已创建对局。可以另存默认值，供以后新对局使用。

| 设置 | 范围 / 默认 | 具体作用 |
| --- | --- | --- |
| 全员手痒 | 0–100 / 0 | 在个人基础上向 100 推高；0 保留个性 |
| 全场上头 | 0–100 / 0 | 提高全员当前上头水平，影响被允许的出手和仓位 |
| 情绪放大 | 0–200% / 100% | 改变连胜连败引起的情绪增量；0 表示关闭胜负驱动的情绪变化 |
| 冷静速度 | 慢、标准、快 / 标准 | 个人上头每完成一轮自然回落 3、6、12 点 |
| 全场变化 | 0–100 / 0 | 增加合格选项间的行为变化，不改变方向证据 |
| 局间奇遇 | 关闭 / 默认关闭 | 二期启用临时卡选择，首版不出现无效开关 |

有效手痒沿用易理解的合成：个人值 + (100 − 个人值) × 全员手痒 / 100。个人值先合并卡片、状态和显式微调，再截断至 0–100。

有效上头采用同样形式合并个人当前上头与全场上头；全场变化同样向上推高个人变化度。情绪放大只调节个人状态的增量，不重复放大全场上头。个人情绪提案初值：每笔盈利 +8 × 敏感度比例 × 情绪放大比例，每笔亏损 +12 × 同样比例；每轮合并新结算事件一次后自然回落。触发后的行为仍按角色的胜负反应解释，谨慎角色可以在情绪增强时缩注，而不是所有人一起追损。

提供三个一键组合：保持本色（手痒 0、上头 0、放大 100%、标准冷静、变化 0）、热闹一点（40、30、100%、标准、20）、全员上头（100、80、150%、慢、50）。预设只改变这些娱乐参数，不改变资金限制。

调节时显示逐角色变化预览，例如“CZ 手痒 62 → 81；仍然只做多 BTC/BNB”。保存后从下一轮生效，本轮已锁定的决定和占卜不改写。下一轮预计算必须按新版本作废重算。通过明确的“应用到下一轮”按钮提交，避免拖动过程中反复修改服务状态。

## 8. 资金设置与冲突优先级

建议默认采用每角色独立本金与账本，沿用现有对局机制，首版阵容仍最多 8 位。

资金面板独立展示：每位本金、单轮下注上限、未结算总暴露上限、允许条件全仓、亏损停止线、盈利停止线。停止线可关闭，配置时明确口径；单轮和总暴露上限取用户设置及角色硬上限中的更严格者。

新版本模拟最低金额建议 0.10U，金额按分向下取整。流派按建议仓位算出低于最低金额时观望，不能向上凑到超额。该规则仅为本地模拟设计，不能用于宣称任何外部平台允许这样的下注金额。

停止条件使用可用余额与已冻结本金构成的净值口径，并清楚注明是否含未结算盈亏。触及停止线停止后续下注，已有未结算订单继续结算；停止线不保证最终净值恰好停在阈值。高仓位和并存未结算订单的最坏损失在开局预览可见。

优先顺序为：

1. 对局停止、数据有效性、账户资金与硬上限。
2. 人物身份规则、依赖顺序、固定档位。
3. 流派方向和行情风险检查。
4. 暂停、冷却等禁止新下注的状态。
5. 卡片、个人属性、全局参数对允许行为的调整。
6. 模型在已获许可的选择范围内给出建议和理由。
7. 最终执行校验并写入模拟账本。

所有限制取交集；没有合法选项就观望。模型、稀有卡、绝招或上头值都不能扩大程序授予的执行权限。

## 9. 抽卡、收藏与卡组版本

首版提供三种入口：经典预设、自由配卡、随机征召。基础卡目录均可浏览和自由试配；“收藏”用于保留喜欢的卡组和外观，不做付费解锁门槛。

随机征召流程：选或抽角色 → 确定流派 → 两次性格三选一 → 绝招三选一 → 看完整行为预览 → 保存参战。每步只从兼容池抽取；同一候选组无重复。专属位只有一张合法卡时直接展示并锁定，不显示假的三选一。

开局前允许免费重抽或转自由配卡。结果连同随机种子、卡池版本和选择记录保存，刷新恢复当前步骤，不凭刷新额外改变同一次抽取。支持主动重新征召，其新种子和记录明确区分。

抽卡动画可跳过，减少动画偏好下直接显示结果。稀有度、羁绊、外号均不能暗中改变数值。首版羁绊只解释已发生的规则互动；额外套装加成留到第二期。

卡组保存时冻结卡片版本、微调、人物依赖与指标配置。修改收藏卡组只影响未来新对局；正在运行的对局持有副本。更换角色时重新检查全部卡位，保留合法项，冲突项明确待替换，不静默删卡。

## 10. UI 改版清单

保留动漫紫、荧光黄、卡通战神，采用角色卡牌作为主要视觉。短文案优先，详细规则逐层展开。主要触控按钮至少 48px，支持手机、平板、桌面及中英文；当前其他已支持语言也纳入回归。

### 10.1 主导航与入口

主导航调整为：战场、卡组、战神榜、战报。原有三个页面的路由保持可访问，新增卡组页。模型连接沿用现有 API/设置入口，卡组卡片上提供模型配置状态和跳转。

### 10.2 卡组大厅

- 顶部主按钮：抽一套、自由组装。
- 列表分为我的卡组、经典预设；提供角色、流派筛选。
- 每张摘要卡显示：角色、外号、五张缩略卡、三个关键属性、方向来源、依赖标记、可用状态。
- 操作：编辑、复制、加入阵容。删除需有恢复或确认机制，避免误删收藏。
- 空状态直接给出“抽第一套”和“使用经典预设”；无效卡组显示缺卡或冲突原因。

### 10.3 抽卡页

- 顶部显示当前步骤与已选卡位，中部三张候选卡。
- 卡片正面只放名称、一句话效果、关键变化；展开后看触发条件、指标和限制。
- 底部固定选择按钮和重抽入口，选择后给出属性差值。
- 特殊人物展示锁形标记和“专属规则”，直白说明不可替换项。

### 10.4 卡组编辑页

桌面采用三栏：左侧角色与卡位、中间候选卡/指标、右侧实时预览。平板采用两栏；手机分为“配卡、指标、资金、预览”四个页签，底部固定保存按钮。

实时预览统一显示：

- 他是谁、怎么看行情、什么时候出手、输了怎么办。
- 基础手痒、当前上头、变化度，以及卡片和全局分别贡献多少。
- 每档建议下注、硬上限、是否能全仓。
- 必需指标、缺失输入、特殊人物依赖。
- “现在为什么不能参战”的明确列表。

高级模式包括个人数值微调、指标参考项和实际规则说明。提示词从同一最终配置生成，区分模板与逐轮实际请求，避免 UI 与执行逻辑说法不一致。

### 10.5 开局页

四步：选择阵容 → 设置币种/周期/本金 → 全局气氛和资金边界 → 确认开打。

确认页展示每位角色的方向来源及依赖顺序。CZ 未入阵、专属币种不支持、凉兮上限不足 50%、最低金额与资金不相容等，在开局前看见。阻断型错误必须处理；合法但可能常观望的组合只解释，不伪装为故障。

### 10.6 战场页

- 顶部：对局选择、轮次、模拟标记、行情状态、全局气氛入口。
- 角色卡：余额/冻结、方向/金额、绝招状态、五卡缩略标记和一句真实决策原因。
- 展开角色：指标依据、性格影响、全局影响、依赖对象、最终执行结果。
- 全局设置在桌面侧栏、手机底部面板展开，明确“当前值”和“下一轮待生效值”。
- 占卜角色展示本轮牌面/卦象，不能只显示泛化 AI 文案。
- 装逼的人显示“等待 CZ”或“本轮反押 CZ”；逆行者显示参考对象和权重摘要。
- 支持 loading、行情失联、模型失败、等待依赖、冷却、观望、资金停止、已结算等独立状态。

### 10.7 战报与战神榜

战报按“来源 → 证据 → 卡片/全局调整 → 限制 → 决定 → 结算”展示。

例如：CZ 本轮有效看涨 → 装逼的人候选看空 → 价差过大 → 本轮观望。即使全员手痒 100，也能看懂没下注的原因。

战神榜保留原有统计，并展示卡组版本、对局气氛和模拟数据标记。不同气氛、资金规则的成绩可筛选，不能把不同条件的名次宣传成策略实力证明。外号和趣味称号只装饰，不改变收益口径。

### 10.8 移动端与可访问性

- 360px 手机宽度无横向溢出，卡片规则不靠悬停才可读。
- 中英文、长名称、长状态和空数据下均可使用。
- 卡牌类别、涨跌和不可用状态同时用文字与图标表达，不只用颜色。
- 支持键盘选择、焦点顺序、读屏标签和跳过抽卡动画。
- Android 构建复用同一策略规则；小组件保留现有金额与状态，在可用空间展示卡组短名或绝招状态，不塞满五卡详情。

## 11. 实现结构与数据保存

沿用当前 JavaScript、DOM、服务与移动端打包，不引入框架迁移。

| 模块 | 计划职责 |
| --- | --- |
| 现有 strategy-catalog | 保留角色键、指标目录及已有判定函数，逐步拆分数据 |
| 新增卡牌目录 | 保存稳定 cardId、版本、类型、文案、适配角色、互斥组、效果参数 |
| 新增卡组编译器 | 把角色、流派、性格、绝招、微调编译成统一执行配置与解释 |
| 新增状态计算模块 | 处理连胜连败、等待、上头、触发、持续、冷却，复用相同事件只处理一次 |
| ai-decision | 接收编译结果，沿用输入检查、策略许可、模型调用与最终校验 |
| prediction-sim / simulation-battles | 保存卡组副本、全局版本、依赖和状态，接入现有账本及预计算 |
| agent-setup / ai-settings | 保留旧配置读取入口，新增卡组编辑并逐步替换旧表单 |
| 新卡组 UI 与现有战场/战报 | 使用统一编译结果展示，不在 UI 再算一套仓位规则 |
| i18n 与移动构建 | 更新中英文和打包输入，校验桌面/手机执行规则一致 |

关键数据对象：CardDefinition、DeckConfig、CompiledPolicy、AgentRoundState、BattleControls、DecisionTrace。卡片效果使用有边界的结构化参数，不允许卡牌文本携带任意可执行代码或提示词权限。

对局保存包括规则版本、卡组哈希、全局设置版本、行情快照标识、占卜种子、依赖快照、已处理事件和逐轮状态。写入沿用现有持久化模式并保证原子性。缺少某版本规则时停止该对局并解释，不能静默使用最新版继续。

预计算只准备可复用的市场分析；仓位、情绪、绝招、资金、全局版本与依赖结果在本轮冻结后校验。任何相关变化都使旧缓存失效。记录模型输入与返回值；固定种子不代表实时市场和外部模型重新调用必然得到同样结果，重放以已记录数据为准。

## 12. 旧策略与存量对局迁移

- 现有 17 个角色保留内部键与当前收藏，新增 v2 卡组格式。
- 老策略可继续作为“经典策略”查看；迁移使用复制，不覆盖原配置。
- 能精确表示的配置映射为默认卡组；不能精确表示的旧属性显示为兼容配置或显式微调，不能假装卡片效果完全等价。
- 已创建的 v1 对局继续使用其原规则及快照；当前全押翻本行为在旧版详情清楚显示，不偷偷转换。
- v2 对局使用新资金规则和情绪逻辑。两种规则版本在战报与榜单可区分。
- v2 卡组编辑不改变正在运行的 v1/v2 对局。全局气氛调整按下一轮生效；资金限制首版只在开局前设置。
- 保留现有存档和回退路径，先通过读取兼容检查，再允许写入新格式。

## 14. 本方案建议采用的关键决定

1. 五卡组装，但特殊人物的方向来源和核心规则不可替换。
2. 指标参与真实判定；性格只改变合法范围内的行为，不提升预测准确率。
3. 全场手痒、全场上头保留，补充情绪放大、冷静速度和全场变化。
4. 首版保留自由配卡与经典预设，抽卡作为有趣的构建方式。
5. 新版移除自动突破仓位上限的翻本例外；小注最低金额改为独立模拟规则。
6. 先验证 UI 原型，再接策略内核与模拟执行；保持旧对局独立和可回退。

下一步为用户审阅本方案，随后按确认范围进入 UI 原型阶段。本次没有实现卡牌功能、修改策略执行或启动任何对局。
