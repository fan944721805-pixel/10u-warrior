# 10U 战神：单卡人物变体策略系统与 UI 方案

日期：2026-09-14。状态：修订设计草案，尚未实现。替代同日“五卡组装”方案。

新增人物提案：在现有 17 个原型之外加入第 18 位 [KZG 口罩哥](2026-09-14_设计-KZG口罩哥人物卡-report.md)，定位技术确认派；已制作基于用户照片的头像设计稿，尚未接入执行。

## 1. 核心定义

**一个策略就是一张完整人物卡。** 玩家抽到“疯狂版凉兮”“谨慎版占卜师”等完整策略，卡上的词条、指标偏好和数值已经组合好。人物、流派、性格、绝招不是可以分别抽取、装卸的卡牌。

生成关系：人物原型 + 兼容的风格词条 + 指标偏好 + 有边界的数值变化 + 可选的特殊状态 = 一张策略卡。

“疯狂版凉兮”仍然是喜欢梭哈的凉兮；“谨慎版占卜师”仍然用塔罗牌决定方向。变体调整的是原人物如何执行自己的方法，不是替换人物的核心玩法。

用户抽到后收藏、比较并派出整张卡。多张完整人物卡组成阵容，一个角色实例运行一个独立策略和账本。

## 3. 一张卡包含哪些内容

| 内容 | 示例 | 是否可随变体变化 |
| --- | --- | --- |
| 人物原型 | 凉兮 | 不变 |
| 变体名称 | 疯狂版凉兮 | 根据真实生成效果命名 |
| 核心人设 | 双向短线、喜欢梭哈、只半仓或全仓 | 不变 |
| 风格词条 | 手痒难耐、连胜膨胀、急于翻本 | 只从人物允许的词条池生成 |
| 指标偏好 | 更关注动量、盘口或拐点 | 在人物允许的方法内变化 |
| 基础属性 | 手痒、情绪敏感度、变化度、出手门槛 | 在人物专属区间变化 |
| 胜负反应 | 连胜更敢全仓、连败更急着找机会 | 保留人物合理的反应范围 |
| 特殊状态 | “让我回本就走” | 可有一个，作为卡片自带词条，不独立装备 |
| 执行约束 | 必需输入、合法方向、合法档位、依赖对象 | 不得被名称或稀有度解除 |
| 收藏信息 | 卡片 ID、抽取时间、版本、来源 | 抽到后固定，可另设昵称 |

每张卡正面最多突出一个主风格和两三个次要词条，避免整面堆满标签。详细数值在背面展开。

## 4. 人设不可变，变体只能在边界内变化

| 人物 | 不可变的核心 | 可变化内容 |
| --- | --- | --- |
| 凉兮 | 喜欢梭哈、短线双向、半仓/全仓或观望 | 参考指标组合、选点严格度、手痒、情绪、合法条件内的全仓倾向 |
| 占卜师 | 三张塔罗牌及正逆位给方向，每轮固定一次 | 指标确认组合、确认严格度、手痒、仓位及胜负反应 |
| 风水师 | 上下卦和五行给方向，每轮固定一次 | 指标确认组合、确认严格度、等待倾向及情绪反应 |
| 装逼的人 | 只反押 CZ 的本轮有效下注 | 对行情风险的敏感程度、出手门槛、仓位及情绪 |
| 逆行者 | 参考其他人的本轮有效下注和历史表现，做加权反押 | 合法范围内的历史权重、亏损敏感度、群体一致性要求和加码倾向 |
| CZ大表哥 | 只做多 BTC、BNB；趋势与流动性框架 | 趋势确认严格度、早期试探意愿、指标侧重 |
| 一姐 | 同类只做多框架，更果断；独立判断 | 确认速度、追击倾向、情绪敏感度 |
| 10U战神 | 激进短线、追冲劲 | 动量与盘口侧重、出手频率、情绪、仓位倾向 |
| 超级AI | 综合信息，分趋势/震荡/危险局 | 各市场状态的侧重、参与意愿、确认门槛 |
| 守财奴 | 小仓位、谨慎、保护利润 | 更看重哪些风险指标、等待程度、缩注速度 |
| 跟风侠 | 顺势跟随 | 趋势周期侧重、确认速度，不变成抄底流 |
| 抄底摸顶王 | 寻找反转 | 超买超卖组合、反转确认严格度、坚持程度 |
| 火箭哥 | 捕捉突破 | 量能确认、突破幅度、追击意愿 |
| 大单侦探 | 资金流与盘口 | 主动流量/盘口权重、流动性要求 |
| 稳如老狗 | 低波动、小仓位 | 风险敏感度、等待耐心、盈利保护 |
| 六票战神 | 固定共识框架与背景过滤 | 确认门槛及允许的权重边界，不靠随意删票改变身份 |
| 蜡烛哥 | 裸 K 形态判断 | 形态偏好、严格度、已支持的周期配置，不暗中改为均线策略 |
| KZG口罩哥（新增提案） | 技术证据决定方向，趋势与结构之后等待确认 | 兼容指标偏好、选点严格度、手痒、情绪、合法仓位倾向 |

不是给所有角色套同一批“疯狂/稳健”词条。“疯狂守财奴”不能越过小仓位核心，首版优先用“精打细算”“异常谨慎”等相符名称。每个人物单独定义可用风格和数值区间。

## 5. 三个具体抽卡例子

下列变体数值是设计示例，尚未实现或验证效果；原版凉兮三项属性来自当前代码。

### 5.1 疯狂版凉兮

卡片展示：

> 疯狂版凉兮
>
> 核心：喜欢梭哈，短线双向，只半仓或全仓。
>
> 风格：手痒难耐 · 连胜膨胀 · 急于翻本
>
> 指标偏好：拐点确认之外，更关注短线动量与主动买卖流。
>
> 手痒 80 · 情绪敏感 100 · 变化度 65
>
> 一句话：还是那个喜欢梭哈的凉兮，只是更容易找到理由入场，符合条件时更偏向全仓。

| 项目 | 当前原版凉兮 | 疯狂版示例 |
| --- | --- | --- |
| 手痒 | 40 | 80 |
| 情绪敏感度 | 95 | 100 |
| 变化度 | 35 | 65 |
| 仓位档位 | 半仓 / 全仓 | 半仓 / 全仓，不变 |
| 方向来源 | 短线行情判断 | 仍是短线行情，侧重可变化 |
| 全仓倾向 | 当前原版条件 | 在允许规则内更容易选择全仓 |

“疯狂”不代表每轮必押，不代表提高模型自报把握去凑全仓条件。没有合法信号照样观望。

也可以抽到“隐忍版凉兮”：出手更少、指标确认更严格，但一旦出手仍半仓或全仓，不能变成 5% 小注。

### 5.2 谨慎版占卜师

核心仍是塔罗牌决定候选方向。变体更看重 ATR、价差、长周期背景，要求更明确的行情支持；牌面看涨但市场条件不允许就观望，不改成看空。

牌面中立时观望。手痒提高只能改变面对有方向牌面时的确认严格度，不能让指标绕过塔罗直接定方向。

### 5.3 激进版风水师

核心仍是上下卦与五行。卦象给出方向后，在行情允许范围内更愿意较早下注，情绪变化更快；不能变成纯技术策略，也不能为得到想要的方向反复起卦。

风水师的卦象相持仍先按原五行规则处理；处理后仍无方向才观望。

## 6. 指标变化与人物核心如何共存

指标配置分为三层：

1. **人物必需输入**：维持人设方法、依赖和风险检查，不能删除。
2. **变体判断输入**：从人物专属允许池选择，实际改变判断或确认方式。
3. **辅助参考信息**：仅供解释或模型参考，明确标注，不伪装成已参与投票。

生成器从经过定义的“指标偏好方案”中选取，再做小范围参数变化，不从全部 26 项指标任意抓几个。每个方案都必须有对应判定规则、有效条件和缺失处理。

允许的变化包括：更重视动量、盘口、趋势背景或波动过滤；在人物许可范围内使用不同确认组合和阈值。指标越多不等于越准确，相关信号不能重复算作独立优势。

对技术人物，指标产生候选方向；对占卜人物，塔罗/卦象产生候选方向，指标检查是否允许执行；对反押人物，目标行为产生候选方向，指标检查风险和可执行性。

方向来源不合法、必需信息缺失、行情过期或资金条件不满足时观望。辅助信息缺失需剔除并记录，不能填 0。变化度影响合法选项间的变化，不抬高证据分数或估计胜率。

## 7. 词条如何组合成一张卡

生成时先确定人物，再选一个主风格，例如疯狂、隐忍、追击、精算；追加少量人物兼容词条和可选状态效果。之后选择兼容指标方案，在人物专属边界内生成属性，最后计算真实行为摘要和名称。

词条不是纯文案。每个词条绑定明确效果：触发条件、调整参数、数值上限、持续轮数、冷却、互斥项、适配人物。名称只能描述实际参数，不先随机取“疯狂”再生成一组保守数值。

数值不采用彼此独立的 0–100 乱抽。采用风格中心值加有限偏移，维护行为一致性；人物硬约束最终校验。半仓/全仓型人物不套用普通仓位倍率，必须在合法档位间选择。

例如“连胜膨胀”可以提高后续合法全仓意愿；“今天不对劲”可以在连败后观察两轮。每张卡首版最多一个有持续/冷却的特殊状态，其他词条采用简单属性或明确事件反应，便于理解。

同一结算只触发一次，刷新或重试不重复加上头。效果只在轮次边界更新，冷却从效果结束后开始，重启不清空状态。暂停类行为优先于增加出手意愿的词条。

## 8. 抽卡与收藏玩法

首版建议两个抽取入口：随机抽一张、指定人物抽变体。指定凉兮就抽不同凉兮，适合比较同一人物的性格差异。

流程：选择卡池 → 揭晓完整人物卡 → 展开词条与原版对比 → 收藏 / 再抽一张 / 加入阵容。取消选角色卡、装流派卡、选性格卡等步骤。

每次抽取生成一个稳定的卡片实例，包含人物键、词条、指标方案、最终数值、种子和规则版本。抽到后固定，刷新与换局不重新随机。主动再抽才产生新实例。

抽取过程、卡池范围和概率应可说明。首版采用符合条件人物等概率、该人物兼容风格等概率，再在各自边界内生成参数；指定人物模式只执行后半段。兼容性通过预先过滤与校验保证，不能靠无限重试偷偷改变概率。无合法候选时解释原因。

首版免费抽取，不做付费、升星、吞卡、碎片或数值成长。完全相同的结果标注重复并可再次收藏，不自动删除或扣除资产。稀有标签可代表罕见组合或外观，不表示更高胜率。

抽到的原卡不可直接覆盖。后续需要手动调整时，从原卡复制为“自定义变体”，仍只编辑人物允许的指标和数值，并保存来源、差异和新版本。首版 UI 优先完成抽取、收藏、比较和参战，手动变体编辑列为高级入口，不回到拼卡玩法。

## 9. 全局设置与卡片属性

一张卡的基础属性是固定的；对局中的上头、冷却和全局影响是运行状态，不写回收藏卡。

| 设置 | 作用 | 不可突破的限制 |
| --- | --- | --- |
| 全员手痒 0–100 | 在各卡基础上提高参与意愿，0 保持原样，100 全员最手痒 | 不能让 CZ 做空、装逼的人脱离 CZ、占卜师跳过塔罗 |
| 全场上头 0–100 | 提高当前对局情绪强度，按不同人物改变合法仓位和出手行为 | 不改人物资金档位，不消除合法信号要求 |
| 情绪放大 0–200% | 放大或减弱胜负引起的个人情绪变化 | 不直接重写固定词条或方向来源 |
| 冷静速度：慢/标准/快 | 控制个人上头回落速度 | 不重抽人物或占卜结果 |
| 全场变化 0–100 | 增加合法选项间的行为变化 | 不添加虚假指标证据 |

默认建议：全员手痒 0、全场上头 0、情绪放大 100%、标准冷静、全场变化 0。

有效手痒使用现有合成形式：个人值 + (100 − 个人值) × 全员手痒 / 100。先计算卡片与合法状态效果，再合并全局，最后截断。其他属性同样保存来源明细，避免重复叠加。

UI 例子：“疯狂版凉兮：卡片手痒 80 → 全局影响后 90”。收藏页始终显示基础 80，战场显示有效 90。

全局指当前对局，可另存默认值用于新局。修改从下一轮生效；已有下注和本轮占卜不变，相关预计算作废重算。手机用底部面板、桌面用侧栏，提交按钮显示“应用到下一轮”。

## 10. 人物依赖、阵容与资金

阵容由最多 8 张完整人物卡构成，沿用现有多角色机制。可以有多个凉兮变体，每张卡运行独立状态和账本，不能只用人物键标识实例。

装逼的人绑定具体 CZ 卡片实例；CZ 缺席、观望、失败、超时或没有本轮有效下注时观望。多个 CZ 不随机换目标。逆行者读取符合条件的其他实例，默认排除自己和其他逆行者，避免循环。

决策按已有顺序扩展：独立人物先完成 → 装逼的人读取绑定 CZ → 逆行者读取合法目标。依赖引用必须同局、同币种、同轮；不引用未执行的模型意向或未结算的未来结果。

资金由对局设置与人物约束共同决定。凉兮只能选择半仓/全仓：若用户限额不允许其中任何一档就观望；不能为了让他下注而改成人设之外的小注。全仓仍需角色允许、策略条件成立且用户限制允许。

上一版提出的“模拟最低 0.10U”和“改变自动翻本规则”均未获确认，不作为此次单卡修订自动实施内容。现有 5U 最低金额和 20% 本金翻本例外应在接入前单独列出影响，确定版本化资金规则；不得因抽卡重构悄悄修改，也不能把资金例外包装为卡片效果。UI 提前显示会使卡片无法出手的条件。

## 11. UI 重新围绕一张卡设计

### 11.1 卡片正面与背面

正面：人物大图、变体名、核心人设标记、两三个词条、关键属性、收藏/参战操作。稀有外观不掩盖规则。

背面或详情：与原版对比、全部词条、指标偏好、出手条件、仓位档位、胜负反应、特殊状态、版本和来源。用“人设固定”和“本次变异”区分不变与变化。

卡面可以显示“疯狂版”“隐忍版”等醒目标签；头像、轮廓、配色保留原人物辨识度。主要采用卡框、表情或背景差异，不为每组随机数生成一张无法辨识的新人图。

### 11.2 页面清单

| 页面 | 内容与主要操作 |
| --- | --- |
| 抽卡 | 选全部人物/指定人物，揭晓一张完整卡；查看、收藏、继续抽 |
| 我的卡册 | 原版与变体列表，按人物/风格筛选，比较、复制、参战 |
| 卡片详情 | 显示原版和本卡差异、指标与人设限制，无装备槽 |
| 我的阵容/开局 | 挑选完整卡片，设置币种周期本金，绑定依赖，调节全局 |
| 战场 | 展示每张卡本轮决定、有效属性、上头状态、依赖、绝招和资金 |
| 战报 | 追溯这张卡怎样从人物规则、指标和词条得出本轮行动 |
| 战神榜 | 展示人物变体、规则版本、全局条件，按同条件筛选 |

主导航建议：战场、卡册、战神榜、战报。抽卡作为卡册中的主入口。原有路由和模型连接继续可达。

### 11.3 典型交互

抽到“疯狂版凉兮”后直接看到整张卡；点击“对比原版”显示手痒 40 → 80、指标侧重变化、半仓/全仓不变。点击“加入阵容”选择对局或新建对局，不再要求装其他卡片。

战场将“卡片基础值”和“全局/状态后的有效值”分开。占卜师详情展示原塔罗牌面、指标支持/反对与最终结果；装逼的人展示绑定的 CZ 变体和实际引用的下注。

手机采用大卡揭晓、纵向详情和固定底部操作；比较视图按同一属性对齐，必要时上下切换，不挤成过窄的表格。桌面支持左右对比和侧栏详情。

继续使用动漫紫、荧光黄、卡通战神，中英文同步。主要触控按钮至少 48px，360px 窄屏可用，动画可跳过，不依赖颜色、悬停或翻译后的文字判断状态。

## 12. 实现与迁移清单

新增数据层：人物原型约束、变体风格目录、词条效果、指标偏好方案、卡片实例。现有 strategy key 保留为人物原型身份，新增独立 cardInstanceId / variantId。

生成器只在抽卡或主动自定义时运行；决策时读取已保存的完整策略参数，不重新随机变体。生成结果经过人物约束和指标可执行性校验，说明与执行共用同一配置。

沿用 strategy-catalog 的原型与已有指标算法，扩展 ai-decision 的输入和最终校验；prediction-sim、simulation-battles 保存卡片快照、独立状态和依赖；agent-setup、战场、战报改为单卡交互。模型配置继续独立，不成为可抽取的卡。

旧角色迁移为“原版人物卡”，保留既有设置与来源，不擅自随机附加词条。不能精确归为原版的已有自定义配置标记为“经典自定义”，保存原值。已创建对局保留自己的规则版本，不被卡册编辑影响。

占卜中立结果的新版观望规则单独记录为行为变更；旧版对局不静默切换。资金规则的未确认变更不混入 UI 改版。

## 13. 阶段与验收

实施次序：确认单卡方案 → 单卡 UI 原型 → 人物变体生成与校验 → 指标/状态/模拟接入 → 迁移与移动端回归。

首版范围：保留现有 17 个原型，并纳入新增 KZG 口罩哥提案，共计划 18 个原型；逐人物配置兼容风格与指标方案；免费随机/定向抽取、完整卡收藏、原版对比、完整卡阵容、既有全局设置及拟议补充项、逐轮可解释战报。风格数量依人物而定，不强行每人同款。

验收清单：

- [ ] 一个策略始终是一张卡；没有角色/流派/性格/绝招的独立卡位或装卸流程。
- [ ] 疯狂版与隐忍版凉兮都只半仓/全仓或观望，指标变化不改变梭哈特色。
- [ ] 占卜师始终由塔罗定方向，风水师始终由卦象与五行定方向；指标不取代它们。
- [ ] 中立占卜结果新版观望；刷新、失败重试、全局变更不重抽当轮占卜。
- [ ] 装逼的人所有变体都绑定具体 CZ，逆行者所有变体都保持群体行为分析。
- [ ] 计划中的全部 18 个原型均有生成检查与执行检查，名称不能掩盖人设漂移；KZG 所有变体保持技术判断来源。
- [ ] 每个指标偏好方案有实际判定用途，必需数据缺失时不会假装有效。
- [ ] 词条、数值与变体名称一致，不生成自相矛盾或无法执行的整卡。
- [ ] 抽取完成后属性固定，刷新不换属性；重复卡不被自动删除。
- [ ] 多张同人物卡在账本、状态、目标绑定和战报中可正确区分。
- [ ] 全局调整只影响当前对局下一轮，卡册基础属性不变，预计算正确失效。
- [ ] 占卜方向、人物依赖、合法档位不能被高上头、高变化或模型输出覆盖。
- [ ] 卡片详情、原版对比、阵容与战报在中英文、手机/平板/桌面可使用。
- [ ] 老配置与运行中对局保持版本隔离；没有把文档提议当作已确认资金改动。
