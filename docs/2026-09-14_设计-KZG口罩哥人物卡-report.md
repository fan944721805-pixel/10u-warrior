# KZG 口罩哥：技术派人物卡与头像概念

状态：人物与头像设计稿，未接入策略运行或 UI。日期：2026-09-14。

本角色加入单卡人物变体方案，作为计划中的第 18 个人物原型。一张 KZG 卡就是一个完整策略，风格词条和指标方案属于这张卡，不是独立装备。

[抖音“口罩哥研报60秒”主页](https://m.douyin.com/share/user/MS4wLjABAAAAnKeRN8QUgooS1pPRqOf_N_jnuztzUyocl0_vUndQFJs)的公开搜索摘要显示简介“我是KZG！”，用于核对用户所指人物。[个人公开站点](https://kzg.one/)列有研报与直播入口。

“技术派”定位来自用户要求。以下指标组合、数值、词条、台词和状态均为游戏原创设计，不是对本人真实交易方法、习惯、收益或胜率的考证，也不表示本人参与或认可本项目。

## 2. 原版人物风格

名称：KZG 口罩哥。建议内部人物键：`kzgMask`。展示定位：技术确认派。

原创游戏台词：“先看结构，再等确认。”

人物核心：根据技术证据产生方向；先看市场趋势与价格结构，再等成交或资金流确认。没有可执行的技术条件就观望，方向失效就重新评估，不靠占卜、跟风或翻本情绪制造方向。

与超级AI的区别：超级AI默认按市场状态切换综合判断重点；KZG默认坚持可解释的“趋势/结构 → 关键位置 → 量能确认”过程。与蜡烛哥的区别：KZG允许技术指标、成交量和盘口辅助，蜡烛哥保留纯裸 K 形态框架。

性格：冷静、挑机会、确认后果断、出错愿意重新看图。赢后不无条件放大风险，连败后提高确认要求。默认不以全仓为特点。

| 属性 | 建议初值 | 表现 |

| 情绪敏感度 | 25 / 100 | 输赢会影响态度，但影响较轻 |

数值为设计初值，尚未进行行为调试。下注比例与金额下限留到整体资金规则确定后统一配置，不能用与当前 5U 下限不相容的小仓位承诺“原版能正常执行”。

## 4. 指标与下注过程

1. 方向背景：使用已支持的长短周期涨跌、EMA、ADX/DMI，区分方向和趋势强弱。
2. 关键位置：使用已收盘 K 线与唐奇安区间边界识别突破或回踩候选；回踩成立需明确连续收盘条件，不能只看一瞬间触碰。
3. 确认：使用成交量倍率、主动买卖流或盘口，检查候选方向是否得到支持。
4. 风险：检查 ATR、价差、行情时效和当前资金条件，最后沿用赔率及执行校验。

指标按证据类别组织，EMA、ADX 等相关信号不能被包装成独立胜率保证。缺少必需数据就观望；“支撑压力”和“回踩确认”必须落为具体算法及测试后才能启用，不以模型口头描述冒充已经实现。

默认可以看涨或看空，由技术条件决定。明确的反向证据使原候选失效；若要转向，必须重新满足另一侧的完整条件。

## 5. 可以抽到的整卡变体

| 完整卡名 | 变化方向 | 必须保留 |
| --- | --- | --- |
| 原版 KZG | 标准技术确认 | 技术证据决定方向 |
| 狙击版 KZG | 更低手痒，更严格关键位置与确认条件 | 找不到确认就等 |
| 追击版 KZG | 更关注突破、成交量与主动流，确认后较快出手 | 不能无量硬追或脱离技术条件 |
| 趋势版 KZG | 更重视 EMA、ADX 和长周期背景 | 不因情绪改为无证据抄底 |
| 疯狂版 KZG | 更高手痒、更早接受允许的技术信号、更积极的合法仓位倾向 | 仍是技术派，不能变成随机梭哈或占卜 |

建议人物生成边界：手痒 20–75、情绪敏感度 10–50、变化度 10–50。更高的全局有效值仍不改变人物方向来源。不同变体适用范围由指标方案决定，不等同于优劣排序。

可选招牌状态词条：“信号共振”。趋势/结构成立且量能或资金流确认达到预设强信号条件时触发，本轮优先使用合法的正常较高档位；一次决策只应用一次。它不增加估计概率，不解除仓位上限，也不是独立可装备卡。具体阈值在实现前落入该人物规则表。

## 6. 头像设计

当前交付：[按用户照片重制的 KZG 头像 v2](images/kzg-mask-bro-avatar-v2.png)。旧概念保留：[v1](images/kzg-mask-bro-avatar-v1.png)。

v2 以用户随后提供的照片作为人物身份与外观参考，修正为更接近照片的宽圆脸、短发、方框眼镜、浅蓝口罩、深绿上衣和黑色领口；v1 仅作为系列画风参考。

- 浅蓝医用口罩：保留“口罩哥”的核心识别点。
- 银色细框眼镜、整洁黑色短发：表现理性和专注。
- 深绿上衣与黑色领口：保留用户照片中的穿着特征和沉稳气质。
- 紫色圆形背景、荧光黄轮廓：与现有 10U 战神角色系列统一。
- 背景少量 K 线和趋势线：说明技术派，不堆数字或伪造终端。
- 无文字头像：卡名由 UI 显示，方便缩小和中英文切换。

生成方式：内置 imagegen。v1 使用现有凉兮头像作为画风与构图参考；v2 使用用户照片作为人物参考、v1 作为画风参考。图片为头像设计稿，不是完整卡片 UI。

变体沿用同一人物识别。狙击版可更冷静，追击版背景突出突破线，疯狂版表情和光效更强；不更换成另一个长相，也不去掉口罩。首版先用本张基础头像，后续再做变体外观。

## 7. 后续接入验收

- 一个 KZG 变体就是一张完整策略卡，没有其他装备卡槽。
- 所有变体均使用技术证据，缺信号不因高全局手痒而任意押注。
- 指标变化有明确计算和判定用途；与现有超级AI、裸K角色的区别能从逐轮记录看到。
- 保留图像来源和原创设计说明，台词不被标成真人原话。
- 卡面、中英文、移动缩略图与人物原型保持对应。
- 本次仅新增设计与头像文件，不修改运行中人物目录、决策流程或已创建对局。
